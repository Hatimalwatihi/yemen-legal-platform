# المنصة العدلية لمكاتب المحاماة في الجمهورية اليمنية

منصة React/TypeScript متكاملة لإدارة مكاتب المحاماة والقضايا والجلسات والوثائق والأرشيف والتشريعات اليمنية وخدمات الذكاء الاصطناعي.

## ما تم تنظيفه وتقويته
- إزالة ملفات مشروع التعبئة/حبيش القديمة من الحزمة الحالية.
- اعتماد `src/App.tsx` كنقطة تشغيل واحدة للمنصة العدلية.
- منع منح صلاحية المدير من واجهة العميل؛ الصلاحية تُقرأ من الخادم فقط.
- جلسات دخول عشوائية تشفيرياً باستخدام `crypto.randomBytes`.
- إلغاء قبول كلمات المرور النصية القديمة.
- تشديد حماية المزامنة والرفع والإدارة وعمليات P2P.
- منع تنزيل ملفات مستخدم آخر عبر التحقق من ملكية الملف للمستخدم.
- دعم عنوان API خارجي عبر `VITE_API_BASE_URL` لتشغيل APK مع خادم Termux/سحابي.
- إزالة مفاتيح/بيانات اتصال شخصية ثابتة من واجهة المنصة العامة.
- أيقونة PWA محلية بدلاً من الاعتماد على رابط خارجي.
- إعداد Capacitor لبناء Android.

## ملاحظة مهمة عن الحجم
حجم المصدر الصغير لا يعني أن المشروع ضعيف. تضخيمه إلى 100–200MB بملفات غير مستخدمة سيزيد زمن التثبيت والبناء فقط، ولا يرفع الأمان أو جودة APK. الحجم الحقيقي لـ APK تحدده مكتبات Android وWebView والبناء النهائي.

راجع `BUILD_APK_TERMUX.md` لبناء APK.
